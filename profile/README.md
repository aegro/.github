# Aegro

Aegro is a farm management platform founded in 2014 in Porto Alegre, Brazil. We build software that connects field operations to the back office — covering crop planning, cost tracking, financial management, and day-to-day farm operations.

## What we build

A single platform where farmers and agronomists manage their entire operation:

- **Planning & Operations** — crop seasons, field activities, input applications
- **Costs & Financials** — production costs, revenue tracking, financial control
- **Inventory & Procurement** — input stock, purchase orders, supplier management
- **Reports & Insights** — productivity analysis, profitability per field

Available on **Web**, **Android**, and **iOS**.

## Public API

We offer a REST API for third-party integrations. Documentation is available at [app.aegro.com.br/docs/public-api](https://app.aegro.com.br/docs/public-api).
